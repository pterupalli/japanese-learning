Overview
What is Kanji?
Kanji are Chinese-origin logographic characters adopted into Japanese. Unlike hiragana and katakana — which represent sounds — each kanji represents a meaning.

日 = sun / day. 本 = origin / book. 語 = language. Combined: 日本語 = Japanese language.

There are 2,136 Jōyō kanji (standard use), but you only need to know about 80 for N5 and 250 for N4. Start here.
日
On-yomi (Chinese reading)
Typically used in compound words. 日 in 日本 (Nihon) uses On-yomi: ニチ/ニ. Usually written in katakana in dictionaries.
月
Kun-yomi (Japanese reading)
Typically used for standalone words. 月 alone = つき (tsuki, moon). Kun-yomi is the native Japanese reading — usually in hiragana.
本
Radicals — the components
Every kanji is built from smaller components called radicals. Learning radicals helps you recognize and remember new kanji faster.
Study method
How to learn kanji effectively
01
Learn the meaning first, then the readings
Know that 水 = water before memorizing its readings (スイ/みず). Meaning anchors everything else.
02
Learn kanji in context — with vocab words
水 alone is abstract. 水曜日 (Wednesday), お水 (water to drink) — context makes it stick. Always pair kanji with real words.
03
Use the Kanji Log in the dashboard
Click any kanji to cycle its status. The log shows On, Kun, meaning, JLPT level, and links to YouTube stroke order guides.
04
Add to Anki for spaced repetition
The Kanji Log shows you what to study. Use Anki (free) for daily SRS review — 20–30 new kanji per week is a solid pace.
